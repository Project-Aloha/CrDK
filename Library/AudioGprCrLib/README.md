# AudioGprCrLib

This stateless portable library encodes an AudioReach GET_SPF_STATE request, decodes bounded GPR version0 headers, and matches replies by domain, port, token and opcode. A basic acknowledgement without an SPF state is a distinct result, never Ready. A decoded DSP error preserves its raw value; CR_SUCCESS means decoding succeeded, not that the DSP command succeeded.

There is no live transport, graph, clock or codec caller. The helper cannot establish a channel epoch, allocate or fence tokens, retain PIL/audio PD state or prove firmware compatibility. Those responsibilities belong to the eventual counted shared GLINK/audio owner. Header extensions are opaque and shift the payload offset. The low client-data nibble stays opaque; reserved high bits and byte7 must be zero. All failure paths preserve caller outputs; input can be unaligned and must remain immutable through the call.

The original implementation uses wire facts from Qualcomm AudioReach Graph Services at `3094583c726710b66eb0204fc5d6a7b336d9e575`: [GPR packet](https://github.com/AudioReach/audioreach-graphservices/blob/3094583c726710b66eb0204fc5d6a7b336d9e575/gpr/api/gpr_packet.h), [basic response](https://github.com/AudioReach/audioreach-graphservices/blob/3094583c726710b66eb0204fc5d6a7b336d9e575/gpr/api/gpr_msg_if.h), [APM](https://github.com/AudioReach/audioreach-graphservices/blob/3094583c726710b66eb0204fc5d6a7b336d9e575/spf/api/apm/apm_api.h). BSD-3-Clause license and Qualcomm attribution are retained in LICENSE. Android OnePlus SM8450 spf-core.c/gpr-lite.h at `877203a7cf9b79973d44a9db716490f95d820110` independently corroborates the24-byte request, APM destination1, domains and response payload. Android host source service3 is not remote AMDB ownership.

Run `python3 Platforms/CranePkg/Tests/run_audio_gpr_tests.py --output .tmp/audio-gpr-tests`. Tests use literal source-derived wire vectors (not device captures), extended/unaligned headers, exact payload/route matching, malformed/oversized packets, aliases and preservation. `check_audio_gpr_arm64.py` compiles actual EFI/WDK ARM64 objects.
