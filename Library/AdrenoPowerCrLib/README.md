# A730 ARC/HFI performance records

`CrAdrenoPowerBuild` constructs validated A730 mainline-family GX/CX performance records from immutable OPP and normalized command-DB snapshots. `CrAdrenoSm8450PowerProfile` supplies the pinned SM8450 reference profile. The builder allocates nothing, performs no IO and does not depend on a live ARC voter. Its256-byte result contains no pointers. Every error preserves the entire output.

The concrete input API is `CrAdrenoPowerBuild(Profile, Gfx, Cx, Mx, Gmxc, Plan)`. Required resources are `gfx.lvl`, `cx.lvl` and `mx.lvl`; `Gmxc=NULL` means the provider has confirmed that optional `gmxc.lvl` is absent. Deferred/not-ready/malformed provider data must not become NULL. The builder independently revalidates the normalized `CR_RPMH_ARC_RESOURCE` names, accelerator3/aligned addresses,2..32 corner entries, monotonic positive entries after index0, zero trailing padding and distinct addresses. A malformed supplied GMxC is an error. The existing `CrRpmhArcQualify` remains the raw LE16 auxiliary-data parser; no second raw parser or hardware voter is introduced here.

The primary index is the first corner at least as large as the requested OPP level. A missing primary match fails. Secondary selection uses the requested level and saturates to the last nonzero corner when none covers it. Packing is `(primary_corner << 16) | (secondary_index << 8) | primary_index`; corner values are not microvolts. Duplicate corner values preserve the first original matching index. Android Gen7 uses the selected primary corner for secondary lookup instead. This library deliberately uses pinned Linux semantics, and a test distinguishes the algorithms when primary rounding changes the answer.

The output matches A730 performance-record field order: GX `{vote, acd, frequency_kHz}`, CX `{vote, frequency_kHz}`. All active frequencies must convert exactly to32-bit kHz. Actual HFI capacities are16 GX/4 CX including off, despite generic GMU scratch arrays being32/6. Off is an explicit0Hz/level0 row, giving vote0; the GX ACD field remainsFFFFFFFF even for off. Unused output slots are zero. A future transport must supply and validate its own HFI version/header/sequence and serialize these records into the exact message; the plan's metadata prefix is not an HFI wire header.

The reference profile includes all12 mainline GPU OPPs plus off and both GMU OPPs plus off. Mainline initializes the GPU performance index to the highest available row,818MHz in this unfiltered reference table.350MHz is an OPP and an Android boot-profile candidate; it is not that mainline selection. Source resume programs GMU200MHz and hub150MHz. These facts do not authorize any frequency transition, establish a speed bin, prove500MHz clock support or override effective board firmware/DT constraints. `Profile` is a trusted immutable provider snapshot; the builder validates its structure and supported chip family, while the consumer qualifies actual source/board/firmware compatibility.

This is the performance-record milestone. A730 has no dynamic `.bcms` catalog, but `a730_build_bw_table` separately builds a fixed12-level HFI bandwidth table using SH0/MC0/ACV plus CN0. That table remains a required later boot dependency. This library does not yet build it, the newer A8xx dependency-vote transport, ACD commands, HFI queues or clock/rail writes.

## Next provider composition contract

1. The real retained GPU session binds its actual PDO/Start incarnation and references the permanent CmdDB provider. Under that provider's rundown, obtain exact-name address and auxiliary snapshots; require exact final status, bound each auxiliary read to64 bytes, and call `CrRpmhArcQualify` into nonpaged session-owned storage. Preserve concrete absence vs not-ready/error for GMxC. Retain immutable source identity/hash and target/firmware selection alongside the profile.
2. Build the plan before any new hardware effects. A successful plan is only checked metadata. It cannot set `ArcWriteQualified`, import or enlarge the existing six-resource APSS handoff, claim a GMU RSCC vote, or allow GPUCC access.
3. The next typed PEP GPU dependency interface must own a separate exact-address lease bound to the real session/PDO/Start/provider incarnation, with `BeginInheritedAccess`, checked fixed `Observe`, `PrepareColdBoot` and `End` phases (names provisional). `PrepareColdBoot` additionally consumes the actual stopped-execution owner's current identity and observations; no caller Boolean substitutes. Existing clock/ARC/ICB owner services perform actual votes under their own serialization. PEP remains the sole GPUCC mapper and must prevent competing raw/reset/domain paths from bypassing the lease.
4. Before live HFI publication, require acknowledged native/ABL GPU/GMU retirement, actual Adreno SMMU route/attachment and backed firmware/queue memory, powered mappings and live IRQ/transport lifetime. The HFI sender owns version/sequence/fence and exact ACK, with partial publication retained until genuine recovery. The checked perf plan neither creates nor proves those dependencies.
5. Close/drain callers, IRQ/DPC/HFI/ring writers and recover physical stop before detaching domains or releasing DMA-visible buffers and power. Failed final cleanup retains exact ownership; assignment loss seals without later MMIO. Normal GMU slumber is not PAS13 shutdown.

No existing provider, native target, catalog, DEC, Windows project or ACPI activation is changed by this library. Root owns those integration points. Planned DEC declaration is `AdrenoPowerCrLib|Include/Library/AdrenoPowerCrLib.h`; managed export must include both sources, header, INF/props, README and GPL license. It depends on the existing exported RpmhArcVoteLib header/types, with no linked calls from the production core.
