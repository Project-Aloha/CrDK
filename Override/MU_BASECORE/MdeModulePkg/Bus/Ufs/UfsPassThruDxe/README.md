# UfsPassThruDxe platform fork

This module preserves the tested native storage/USB behavior without further functional edits to official MU sources. It is selected explicitly by the platform DSC/FDF and must not be packaged alongside the original module (same FILE_GUID and BASE_NAME).

Baseline: MU_BASECORE `562c0927ef7bfc65d26d9caf322e569ccb23b6a9`, `MdeModulePkg/Bus/Ufs/UfsPassThruDxe`. `PROVENANCE.json` records each baseline, captured source, and fork hash. `MU_BASECORE.patch` records the cumulative functional delta; it applies to the baseline repository, not the fork directory. All original source licenses remain intact. The copied closure contains the INF-listed sources, local headers, and UNI metadata, with no copied package headers or libraries.

The C/header/UNI bytes were unchanged at relocation. UFS100 now binds NOP, Query and SCSI Task Tags to reserved transfer slots, validates response identity, and captures controller registers on failed SCSI completion. UFS101 checks sticky HCI fatal errors before submission and completion, closes admission and stops the whole controller before cleanup; a failed stop retains every DMA allocation. The native host adapter captures the owned SID fault/register/page-table state and live DMA spans before that stop. These corrections establish error handling and diagnostics; the board SBFE cause and usable UFS storage still require a new capture. The INF remains byte-identical to its captured original. See `PROVENANCE.json` for the open-source Linux/Android reference revisions and post-relocation scope.

Necessity audit and regression mapping: `.tmp/waipio-continuation/mu-audit71/storage-usb.md`. This relocation is not a new hardware qualification.

UFS102 uses the public Android/Linux UCD layout with 512-byte command and response regions and PRDT after both. It clears the complete TRD header on reuse and rejects query descriptors larger than Android QUERY_DESC_MAX_SIZE255. First-four-request traces record CPU-owned UTRD/UPIU bytes and doorbell attempts/accepted writes, without dereferencing IOVAs. A new disjoint CPU/IOVA oracle covers all32 slots, a33-bit address, maximum query size and multi-PRD transfers while keeping the next NOP page ungranted. The board translation fault at10003000 is confirmed; these source/host changes are a candidate adaptation and do not establish its physical cause or resolution.

UFS103 adopts public Waipio Android's persistent all-slot UCD array:512-byte command/response regions and12816-byte PRDs per3072-byte slot. All TRD UCD addresses and fixed offsets exist before RunStop, including NOP/Query PRDT offset1024 with zero length. Requests borrow slots without releasing the controller mapping; stop/revocation/free failures retain ownership for retry. Transfers above32MiB report EFI_BAD_BUFFER_SIZE and the supported maximum. The full backed allocation changes DMA coverage according to the real descriptor array, with no unbacked guard grant. The old-source negative establishes an Android initialization-contract difference only. The physical next-page read and successful enumeration still require board validation.
